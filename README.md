原燕大终端 Android 客户端的重生版本，基于原版代码库独立维护。

## 这是什么

这个账号发布燕大终端的重生版客户端。代码派生自原项目，目前由我们独立维护；源码不通过公开仓库直接发布，但按照 GPLv3 要求向获得二进制版本的用户提供。

## 下载与反馈

新版本通过 [GitHub Releases](../../releases) 发布，问题反馈与功能建议请提交到 [Issues](../../issues)。请查看 Release 说明中的更新内容、校验和与已知问题。

## 许可与源码获取

- **许可证**：原项目以 GPLv3 发布。由于重生版基于其代码派生，因此同样遵循 GPLv3。
- **源码申请**：如果你获得了本软件的二进制分发版本，有权索取对应版本的完整源码。请发送邮件至 `yanda_terminal@proton.me`，说明你的身份、使用场景和所获构建版本。我们会定期集中审核并通过邮件回复发送源码压缩包。
- **安全提示**：如果你不信任由第三方团队继续维护的软件，可以选择不使用。
